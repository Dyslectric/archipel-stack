# Interface styles

Choose **Settings → Personal → Appearance** to switch between Default, Fusion
Compact and Fusion Cozy. The choice is saved in this browser; Light, Dark and
Device are independent color choices. Switching styles preserves composer drafts.
Fusion starts with 15px text and larger reaction emoji. The Text size slider scales
every interface style from 85% to 175%, independently of the color scheme and style.

Fusion follows the saved Claude mockups: rounded top tabs, framed gray panes,
subtle button gradients, blue selected rows and Segoe UI. Compact uses time,
author and message columns without avatars; Cozy shows avatars beside messages,
members, posts and nested replies. Both have collapsible thread headers, a channel
directory table and a channel creation dialog. Touch controls keep 44px targets.

In a threaded channel each post and reply is one row, indented under the message it
answers; the chevron beside a reply folds what is under it. Selecting a row makes it
the message the composer answers, as the composer's label says; New thread goes back
to starting a thread, keeping a title you had begun. In the channel directory, select
a row and double-click it to open or join that channel; section headings fold. The
status strip shows the connection, the conversation or directory on screen, and a hint.

Fusion quotes preview the original message above the composer. Remove the quote
without changing the draft, or send it as Markdown with a reply link to the
original channel message. In threads, Quote replies to the selected post or reply.
Choose Edit quote to shorten or change the quoted text. Place the cursor between
passages and choose Split at cursor to answer sections separately. Preview quote
shows the edited sections; sending preserves their order and the source reply link.
Select a row to use Reply, React or Quote in the command bar; the arrow keys move
between rows. Right-click a message (or press Shift+F10) to copy, edit or remove it.
Search filters messages loaded in the current conversation.
Existing emoji previews, profile menus and reaction pickers share the Fusion palette.
Hover or focus a reaction to preview its emoji; on touch, hold the reaction. Previewing
does not toggle the reaction. Closed and open folder icons toggle a channel's subjects in the sidebar
without opening the conversation. Remote globes sit beside names before their row menu.

Instance administrators can use **Settings → Other servers → Featured channels**
to enable, select, order and remove recommendations. Only public external channels
already followed by someone on the instance are eligible. The directory publishes
their names and descriptions, not their archives or member lists. Subscribing
still requires federation permissions and acceptance by the home instance.
Private, blocked, deleted or no-longer-followed channels disappear from recommendations.

Fusion's hash, world and needle-thread icon paths come from [Tabler Icons](https://github.com/tabler/tabler-icons),
under its MIT license (see [the bundled notice](licenses/tabler-icons.txt)). The
monochrome XMPP mark is the simplified illustration from the approved mockups.
